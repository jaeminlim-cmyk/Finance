# AI 헤지펀드 — 미국 주식 멀티 에이전트 모의 자동매매

서로 다른 역할을 맡은 AI 직원들이 분석 보고서를 내고, 매수·매도 측이 토론하고, 리스크 관리자가 검토한 뒤
수석 트레이더가 최종 결정하는 구조로 미국 주식을 **모의투자**하는 시스템입니다. 모든 과정은 웹 대시보드에서 볼 수 있습니다.

> **이 시스템은 투자 조언이 아닙니다.** 1단계는 100% 가상(페이퍼) 매매이며 실제 주문이 나가는 코드 경로가 없습니다.
> 모의투자·백테스트 성과는 실거래 수익을 보장하지 않습니다.

원래 요구사항은 [`PROMPT.md`](PROMPT.md) 에 있습니다.

## 빠른 시작

API 키 없이 샘플 데이터와 가짜 LLM 응답으로 전체 흐름을 바로 돌려 볼 수 있습니다.

```bash
# 1) 백엔드
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

# 2) 대시보드 빌드 (결과물을 백엔드가 함께 서빙합니다)
cd ../frontend && npm install && npm run build

# 3) 최근 60거래일을 빠르게 재생해 기록을 채우고 서버 실행
cd ../backend
python -m app.cli simulate --days 60
uvicorn app.api:app --port 8000
```

브라우저에서 <http://127.0.0.1:8000> 을 엽니다. Docker 를 쓰려면 저장소 루트에서 `docker compose up --build` 입니다.

인증이 없는 로컬 도구입니다. 킬 스위치·초기화 같은 제어 기능이 있으므로 인터넷에 그대로 노출하지 마세요.

### 실제 데이터와 Claude 로 돌리기

`.env.example` 을 `.env` 로 복사해 모드를 바꿉니다. 두 모드는 따로 켤 수 있습니다.

| 설정 | 값 | 설명 |
|---|---|---|
| `TRADING_MODE` | `paper` | 다른 값이면 서버가 시작을 거부합니다 |
| `DATA_MODE` | `mock` / `live` | `live` 는 yfinance 시세·재무·뉴스 (`pip install -e ".[live]"` 필요) |
| `LLM_MODE` | `mock` / `anthropic` | `anthropic` 은 Claude 를 호출하며 **실제 비용이 발생**합니다. `ANTHROPIC_API_KEY` 필요 |
| `FINNHUB_API_KEY` | 선택 | 있으면 뉴스를 Finnhub 에서 가져옵니다 (과거 날짜 조회 가능) |
| `REDDIT_CLIENT_ID/SECRET` | 선택 | 있으면 커뮤니티 데이터에 Reddit 검색을 더합니다 |

한도·모델·일정은 [`config/fund.toml`](config/fund.toml) 에서 바꿉니다.

## 의사결정 흐름

```
종목 선별 (코드: 유동성·움직임·뉴스로 후보 10개)
  → 매크로 분석 → 스캘핑 후보 선정
  → 리서치 본부 병렬 분석 → 합의 점수 계산 (적중률이 쌓이면 직원별 가중치 조정)
  → 상위 후보만 매수 대 매도 토론 → 트레이더 매매안 → 리스크 관리자 검토 → 수석 트레이더 결정
  → 하드 리스크 규칙 검사 (코드) → 페이퍼 브로커 체결
  → 전 과정 기록 → 청산 뒤 성과 분석가 복기
```

- 보유 종목은 회의마다 다시 검토합니다. 합의 점수가 나빠지면 정식 토론을 거치고, 아니면 수석 트레이더가 약식으로 재검토합니다.
- 숫자(지표·재무비율·포지션 크기)는 모두 코드가 계산해 넘깁니다. 에이전트는 구조화된 출력(JSON 스키마)으로만 답합니다.
- 뉴스·커뮤니티 글은 `<untrusted_external_content>` 로 감싸 전달하고, 그 안의 지시문은 따르지 않도록 지시합니다.
- 리스크 관리자가 거부한 매수는 수석 트레이더가 매수로 답해도 코드가 관망으로 바꿉니다.

## 리스크 관리

아래 규칙은 주문 직전에 코드([`backend/app/risk.py`](backend/app/risk.py))가 검사합니다. 어떤 에이전트의 결정도 넘을 수 없습니다.

| 규칙 | 기본값 |
|---|---|
| 종목당 최대 비중 | 10% |
| 섹터당 최대 비중 | 30% |
| 최소 현금 비중 | 10% |
| 거래당 최대 손실 위험 (진입가~손절가) | 자본의 1% |
| 손절가 | 필수. 없거나 비상식적이면 ATR × 2 로 교정 |
| 일일 손실 한도 | −3% → 당일 신규 진입 중단 |
| 고점 대비 낙폭 한도 | −15% → 전체 중단, 사람이 대시보드에서 재개 |
| 실적 발표 전 | 2거래일 전부터 신규 진입 금지 |
| 유동성 | 주가 $5 미만, 평균 거래대금 $2,000만 미만 제외 |
| 스캘핑 자본 | 자본의 10% |
| 그 밖에 | 정규장 시간에만 주문, 공매도 불가, 스캘핑은 장 마감 전 전량 청산 |

**킬 스위치**를 켜면 신규 매수와 회의 결정에 따른 매도가 모두 멈추고 스캘핑 포지션은 즉시 청산됩니다.
이미 걸려 있는 손절·목표가 청산은 계속 동작합니다(보호 장치를 끄지 않기 위해서입니다).

데이트레이딩 관련 규정(PDT 등)은 계좌 종류와 시점에 따라 달라 코드로 강제하지 않았습니다. 실거래 전환 전에 최신 규정을 확인해 반영해야 합니다.

## 시뮬레이션과 백테스트

- **페이퍼 브로커**: 슬리피지 5bp, 주당 $0.005 수수료(최소 $1), 봉 거래량의 5%까지만 체결(부분 체결)을 모델링합니다.
- **백테스트**: `python -m app.cli backtest 2024-01-02 2024-03-28` 또는 대시보드 「성과 분석」. 운용과 같은 파이프라인을 과거 날짜에 하루씩 재생하며, 별도 DB(`data/backtests/`)를 씁니다.
- **미래 정보 차단**: 모든 데이터는 `MarketData` 를 거치고, 현재 시계 시각 이후의 항목이 하나라도 섞이면 `LookaheadError` 로 중단합니다. 과거 시점 조회가 안 되는 소스(실데이터의 재무·커뮤니티 등)는 백테스트에서 '데이터 없음'으로 처리합니다.
- **한계**: 실제 LLM 은 학습 과정에서 과거 사건을 이미 알고 있을 수 있어, 학습 시점 이전 구간의 백테스트 성과는 낙관적으로 나올 수 있습니다. 코드로 막을 수 없는 한계입니다.
- **일봉 시뮬레이션의 가정**: 스윙 진입은 당일 시가에 체결, 손절·목표가는 당일 저가·고가로 판정하며 둘 다 닿으면 손절이 먼저였다고 봅니다. 장전 회의만 재생하고 장중 재검토는 재생하지 않습니다.
- **성과 지표**: 누적 수익률, 벤치마크(SPY) 대비 초과수익, 샤프 지수, 최대 낙폭, 승률, 손익비, 거래 횟수, LLM 비용 차감 후 순수익.

## LLM 비용 관리

- 모든 호출의 토큰과 비용을 기록합니다. 같은 입력의 반복 호출은 캐시에서 돌려줍니다.
- 이번 달 누적 비용이 예산(기본 $100)의 70% 를 넘으면 회의 규모를 줄이고, 90% 를 넘으면 보유 종목만 검토하고, 100% 에서 호출을 멈춥니다. 손절·청산 같은 코드 기반 보호는 계속 동작합니다.
- 비용은 코드에 넣어 둔 단가표([`anthropic_llm.py`](backend/app/llm/anthropic_llm.py))로 추정한 값입니다. 실제 청구액과 다를 수 있으니 처음에는 Anthropic 콘솔의 사용량과 대조해 보세요.
- 장중에는 크게 움직였거나 새 뉴스가 나온 보유 종목만 다시 검토합니다.

## 테스트

```bash
cd backend && python -m pytest
```

달력, 지표, 미래 정보 차단, 페이퍼 브로커 장부, 하드 리스크 규칙, LLM 예산·캐시, 회의 파이프라인(리스크 거부 강제 포함),
스캘핑 신호와 장 마감 청산, 시뮬레이션 재현성과 장부 정합성, 스케줄러 하루 사이클, API 를 검증합니다.

## 검증 상태

| 항목 | 상태 |
|---|---|
| 샘플 데이터 + 가짜 LLM 으로 전체 흐름, 대시보드 | 테스트와 실제 화면으로 확인 |
| Claude 연동 (`LLM_MODE=anthropic`) | 코드는 SDK 문서와 설치된 SDK 시그니처에 맞춰 작성했으나 **API 키가 없어 실제 호출은 해 보지 못함** |
| 실데이터 (`DATA_MODE=live`) | 실제 야후·StockTwits 데이터로 공급자의 모든 항목, 회의 1회, 7거래일 백테스트를 실행해 확인 (LLM 은 가짜 응답). 야후는 비공식 경로라 형식이 바뀌면 깨질 수 있고, 요청이 몰리면 일부 종목의 재무가 일시적으로 비어 '데이터 없음'으로 보고될 수 있음 |
| Finnhub 뉴스, Reddit 검색 | 키가 없어 **실행해 보지 못함** |
| Docker 이미지 | 개발 환경에 Docker 데몬이 없어 **빌드해 보지 못함** |
| Alpaca Paper Trading 연동 | 미구현 (브로커 인터페이스만 있음) |
| 경제 일정(FOMC·CPI 등) | 미연결. 매크로 분석가는 '데이터 없음'으로 보고 |

처음 실데이터·Claude 로 전환할 때는 `python -m app.cli meeting` 으로 회의를 한 번만 돌려 보고 결과와 비용을 확인한 뒤 스케줄러를 켜는 것을 권합니다.
